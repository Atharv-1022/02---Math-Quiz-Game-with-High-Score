# 🧮 Math Quiz Game – Python Project 02

## 📌 About the Project

This is my second Python project, a command-line Math Quiz Game built using Python.

The game generates random mathematical questions using four basic arithmetic operators: addition (+), subtraction (-), multiplication (*), and division (/).

The player answers each question, earns points for correct answers, and the game ends when an incorrect answer or invalid input is entered.

The program also saves the highest score in a text file so that the player's progress is maintained between game sessions.

## ✨ Features

- Random number generation.
- Random mathematical operations.
- Supports addition, subtraction, multiplication, and division.
- Accepts user answers.
- Checks answers using `math.isclose()`.
- Tracks the current score.
- Handles invalid inputs using exception handling.
- Saves and retrieves the high score using file handling.
- Displays congratulations when a new high score is achieved.

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python 02_Math_Quiz_Game.py
```
